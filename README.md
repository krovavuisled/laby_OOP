## Завдання

Варіант 6. Створити клас Triad для трійки чисел із методами зміни полів та обчислення суми. Створити похідний клас Triangle, поля якого є сторонами трикутника; реалізувати обчислення кутів і площі. Додати функцію, яка приймає та повертає об’єкт базового класу, і продемонструвати принцип підстановки.

## Проєкт Visual Studio

Рішення містить консольний проєкт `lb8_OOP`. Файли вихідного коду збережено
без змін відносно підготовленої лабораторної роботи.

Файли рішення та вихідного коду:

- `lb8_OOP.sln`
- `lb8_OOP.slnx`
- `lb8_OOP/lb8_OOP.vcxproj`
- `lb8_OOP/lb8_OOP.vcxproj.filters`
- `lb8_OOP/main.cpp`

## Збирання та запуск

1. Завантажити гілку `lab8` репозиторію `laby_OOP`.
2. Відкрити `lb8_OOP.slnx`; за потреби використати `lb8_OOP.sln`.
3. Вибрати `Debug` або `Release`, платформа `x64`, та зібрати рішення.
4. Запустити консольний проєкт `lb8_OOP` без аргументів для демонстрації.

У проєкті задано C++17, вимкнено предкомпільовані заголовки. Потрібні
засоби розробки класичних програм C++ та встановлений Windows SDK.
Обидва файли рішення відкривають той самий набір проєктів.

## Перевірка

Рішення успішно зібрано в Debug x64 і Release x64. Демонстраційний вивід
