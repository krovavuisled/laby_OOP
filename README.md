## Завдання

Варіант 6. Реалізувати обчислення суми геометричної прогресії у чотирьох варіантах: без специфікації винятків, із throw(), із конкретною стандартною специфікацією та з власними винятками. Власний виняток подати порожнім класом, незалежним класом із параметрами та нащадком std::exception із параметрами. Продемонструвати перехоплення всіх видів помилок у main().

## Збирання та запуск

1. Завантажити гілку `lab7` репозиторію `laby_OOP`.
2. Відкрити `lb7_OOP.slnx`; за потреби використати `lb7_OOP.sln`.
3. Вибрати `Debug` або `Release`, платформа `x64`, та зібрати рішення.
4. Запустити консольний проєкт `lb7_OOP` без аргументів для демонстрації.

У проєкті задано C++14, вимкнено предкомпільовані заголовки. Потрібні
засоби розробки класичних програм C++ та встановлений Windows SDK.
Обидва файли рішення відкривають той самий набір проєктів.

## Особливість лабораторної 7

Завдання вимагає старі специфікації `throw(Тип)`, тому задано C++14.
MSVC приймає їх із попередженням C4290 і не перевіряє список типів;
перевірки параметрів та обробники реалізовано у вихідному коді.
Пояснення: [Microsoft C4290](https://learn.microsoft.com/en-us/cpp/error-messages/compiler-warnings/compiler-warning-level-3-c4290).
