# Лабораторна робота 9 — Віртуальні функції

**Виконав:** Гончаренко Олександр Олександрович  
**Група:** 204-ТН  
**Варіант:** 1

## Завдання

Варіант 1. Від Base створити DerA і DerB, а від них шляхом множинного успадкування — DerAB. Перевизначити myname() для виведення фактичного імені класу. Викликати метод для об’єктів усіх чотирьох класів та для чотирьох динамічних об’єктів через масив покажчиків на Base. Пояснити результати й відповісти на контрольні запитання.

## Проєкт Visual Studio

Рішення містить консольний проєкт `lb9_OOP`. Файли вихідного коду збережено
без змін відносно підготовленої лабораторної роботи.

Файли рішення та вихідного коду:

- `lb9_OOP.sln`
- `lb9_OOP.slnx`
- `lb9_OOP/lb9_OOP.vcxproj`
- `lb9_OOP/lb9_OOP.vcxproj.filters`
- `lb9_OOP/main.cpp`

## Збирання та запуск

1. Завантажити гілку `lab9` репозиторію `laby_OOP`.
2. Відкрити `lb9_OOP.slnx`; за потреби використати `lb9_OOP.sln`.
3. Вибрати `Debug` або `Release`, платформа `x64`, та зібрати рішення.
4. Запустити консольний проєкт `lb9_OOP` без аргументів для демонстрації.

У проєкті задано C++17, вимкнено предкомпільовані заголовки. Потрібні
засоби розробки класичних програм C++ та встановлений Windows SDK.
Обидва файли рішення відкривають той самий набір проєктів.

Для цієї роботи окремо обрано варіант 1 — ієрархію Base, DerA, DerB та DerAB.
