## Завдання

Створити клас `Angle` для роботи з кутами на площині, заданими градусами та хвилинами.
Поля класу закриті. Реалізовано:

- `Init()`, `Read()`, `Display()`, `toString()`;
- `radians()` — переведення кута в радіани;
- `normalize()` — приведення до діапазону `[0°, 360°)`;
- `increase()` і `decrease()` — збільшення та зменшення на інший кут;
- `sine()` — обчислення синуса;
- `compare()` — порівняння кутів, результат `-1`, `0` або `1`.

Повне значення зберігається як `60 * degrees_ + minutes_` кутових хвилин.
Градуси та хвилини враховуються алгебраїчно: пара `-30 -30` задає `-30°30′`,
а `0 -30` — `-0°30′`. Під час `Init()` хвилини мають бути від `-59` до `59`.
Контролюються числове введення та діапазон значень; помилки обробляються в `main()`.

проєкт; достатньо відкрити один.

## Відкриття у Visual Studio

1. Завантажити архів саме гілки `lab2` або клонувати її.
2. Відкрити `lb2_OOP.slnx`; за потреби використати `lb2_OOP.sln`.
3. Вибрати `Debug` або `Release`, платформа `x64`.
4. Зібрати та запустити проєкт. Потрібні засоби розробки класичних програм C++
   і встановлений Windows SDK. У проєкті задано C++17 і вимкнено PCH.

Без аргументів програма послідовно читає два кути. Приклад введення:

```text
30 30
45 0
```

Щоб повторити демонстрацію зі звіту, задати аргумент командного рядка `--demo`.

## Демонстраційний вивід

```text
a = 30 deg 30 min
b = 45 deg 0 min
radians(a) = 0.532325
sin(a) = 0.507538
compare(a,b) = -1
a + b = 75 deg 30 min
restored a = 30 deg 30 min
normalized -30 deg 30 min = 329 deg 30 min
Invalid input: Invalid degrees or minutes
```

## Перевірка

Проєкт перевірено у конфігураціях Debug x64 і Release x64.
Вивід `--demo` збігається зі звітом. Перевірено правильне введення,
від’ємні хвилини, недопустимі хвилини та нечислові дані.

Файли Visual Studio та вихідний код розміщено в окремій гілці `lab2`
репозиторію `laby_OOP`. Результати збирання й тимчасові файли виключені
через `.gitignore`.
