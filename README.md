## Завдання

Виконати всі чотири пункти спільного завдання: визначити абстрактний клас трикутників і реалізації за трьома сторонами та трьома вершинами; додати побудову за основами трьох медіан і обчислення довільної медіани; знаходити середню лінію, паралельну довільній стороні; створити похідний прямокутний трикутник та обчислювати радіуси вписаного й описаного кіл.

## Проєкт Visual Studio

Рішення містить консольний проєкт `lb10_OOP`. Файли вихідного коду збережено
без змін відносно підготовленої лабораторної роботи.

Файли рішення та вихідного коду:

- `lb10_OOP.sln`
- `lb10_OOP.slnx`
- `lb10_OOP/lb10_OOP.vcxproj`
- `lb10_OOP/lb10_OOP.vcxproj.filters`
- `lb10_OOP/main.cpp`

## Збирання та запуск

1. Завантажити гілку `lab10` репозиторію `laby_OOP`.
2. Відкрити `lb10_OOP.slnx`; за потреби використати `lb10_OOP.sln`.
3. Вибрати `Debug` або `Release`, платформа `x64`, та зібрати рішення.
4. Запустити консольний проєкт `lb10_OOP` без аргументів для демонстрації.

У проєкті задано C++17, вимкнено предкомпільовані заголовки. Потрібні
засоби розробки класичних програм C++ та встановлений Windows SDK.
Обидва файли рішення відкривають той самий набір проєктів.

Виконано всі чотири пункти спільного завдання. Побудова за основами медіан
використовує координати середин трьох сторін трикутника.
