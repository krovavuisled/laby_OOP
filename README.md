## Завдання

Використовуючи проєкт лабораторної роботи 3, створити статичну бібліотеку та окремий консольний додаток, який демонструє її функціонал. Користувацький тип даних варіанта 6 — Angle.

## Проєкт Visual Studio

Рішення містить консольний клієнт `lb5_OOP` і статичну бібліотеку `AngleStatic`.
Клієнт містить `main.cpp`, а клас Angle реалізований лише в бібліотеці.
Залежність проєктів і підключення бібліотеки задані у файлах рішення та проєкту.
ЛР5 використовує клас із лабораторної роботи 3.

Файли рішення та вихідного коду:

- `lb5_OOP.sln`
- `lb5_OOP.slnx`
- `lb5_OOP/lb5_OOP.vcxproj`
- `lb5_OOP/lb5_OOP.vcxproj.filters`
- `lb5_OOP/main.cpp`
- `AngleStatic/AngleStatic.vcxproj`
- `AngleStatic/AngleStatic.vcxproj.filters`
- `AngleStatic/Angle.h`
- `AngleStatic/Angle.cpp`

## Збирання та запуск

1. Завантажити гілку `lab5` репозиторію `laby_OOP`.
2. Відкрити `lb5_OOP.slnx`; за потреби використати `lb5_OOP.sln`.
3. Вибрати `Debug` або `Release`, платформа `x64`, та зібрати рішення.
4. Запустити консольний проєкт `lb5_OOP` без аргументів для демонстрації.

У проєкті задано C++17, вимкнено предкомпільовані заголовки. Потрібні
засоби розробки класичних програм C++ та встановлений Windows SDK.
Обидва файли рішення відкривають той самий набір проєктів.

Аргумент `--read` після демонстрації додатково вмикає введення кута.
Наприклад, `0 -30` задає від’ємний кут у пів градуса; хвилини — від -59 до 59.

Рішення успішно зібрано в Debug x64 і Release x64. Демонстраційний вивід
