# Лабораторна робота 4 — Перевантаження операцій в C++

**Виконав:** Гончаренко Олександр Олександрович  
**Група:** 204-ТН  
**Варіант:** 6

## Завдання

Використовуючи клас Angle з лабораторної роботи 3, визначити й реалізувати 3–4 перевантажені операції. Для варіанта 6 обрано +, -, == і <. Продемонструвати їх роботу та зберегти базові методи класу.

## Проєкт Visual Studio

Рішення містить консольний проєкт `lb4_OOP`. Файли вихідного коду збережено
без змін відносно підготовленої лабораторної роботи.

Файли рішення та вихідного коду:

- `lb4_OOP.sln`
- `lb4_OOP.slnx`
- `lb4_OOP/lb4_OOP.vcxproj`
- `lb4_OOP/lb4_OOP.vcxproj.filters`
- `lb4_OOP/Angle.h`
- `lb4_OOP/Angle.cpp`
- `lb4_OOP/main.cpp`

## Збирання та запуск

1. Завантажити гілку `lab4` репозиторію `laby_OOP`.
2. Відкрити `lb4_OOP.slnx`; за потреби використати `lb4_OOP.sln`.
3. Вибрати `Debug` або `Release`, платформа `x64`, та зібрати рішення.
4. Запустити консольний проєкт `lb4_OOP` без аргументів для демонстрації.

У проєкті задано C++17, вимкнено предкомпільовані заголовки. Потрібні
засоби розробки класичних програм C++ та встановлений Windows SDK.
Обидва файли рішення відкривають той самий набір проєктів.

Аргумент `--read` після демонстрації додатково вмикає введення кута.
Наприклад, `0 -30` задає від’ємний кут у пів градуса; хвилини — від -59 до 59.

## Перевірка

Рішення успішно зібрано в Debug x64 і Release x64. Демонстраційний вивід
збігається зі звітом. У GitHub зберігаються вихідні файли та файли Visual Studio;
тимчасові файли й результати збирання виключено через `.gitignore`.
