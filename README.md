## Завдання

Реалізувати структуру-пару для обчислення загальної калорійності продукту:

- `first` — ціле додатне число, калорійність 100 г продукту;
- `second` — дробове додатне число, маса продукту в кілограмах;
- `Init()` — перевірка та ініціалізація даних;
- `Read()` — введення з клавіатури;
- `Display()` — виведення даних та результату;
- `power()` — обчислення загальної калорійності.

Формула: `E = first * second * 10`, оскільки 1 кг містить десять порцій по 100 г.

## Файли проєкту

```text
laby_OOP
├── .gitattributes
├── .gitignore
├── README.md
├── lb1_OOP.slnx
├── lb1_OOP.sln
└── lb1_OOP
    ├── lb1_OOP.vcxproj
    ├── lb1_OOP.vcxproj.filters
    ├── Product.h
    ├── Product.cpp

```

`Product.h` містить оголошення структури, `Product.cpp` — реалізацію методів,
`main.cpp` — головну програму. `.slnx` і `.sln` відкривають той самий проєкт;
достатньо відкрити один із них.

## Відкриття у Visual Studio

1. Завантажити та розпакувати проєкт або клонувати репозиторій.
2. Відкрити `lb1_OOP.slnx`; за потреби використати `lb1_OOP.sln`.
3. Вибрати `Debug` або `Release` та платформу `x64`.
4. Зібрати й запустити проєкт. Потрібні засоби розробки класичних програм C++
   та встановлений Windows SDK.

За замовчуванням програма читає два значення з клавіатури. Наприклад:

```text
250 0.3
```

Результат: `750.00 kcal`.

Для демонстрації з даними зі звіту задати аргумент командного рядка `--demo`.
Без цього аргументу потрібно ввести дані вручну.

## Демонстраційний вивід

```text
250 kcal/100g; 0.30 kg
Total: 750.00 kcal
100 kcal/100g; 1.00 kg
Total: 1000.00 kcal
Init(0, 1): false
Init(100, -1): false
State after invalid input: 100 kcal/100g; 1.00 kg
Total: 1000.00 kcal
```

Нульові, від’ємні й нескінченні значення та переповнення результату відхиляються.
Невдала ініціалізація не змінює попередній коректний стан структури.
