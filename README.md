**Виконав:** Гончаренко Олександр Олександрович  
**Група:** 204-ТН

## Завдання

Використовуючи проєкт лабораторної роботи 4, створити динамічну бібліотеку та окремий консольний додаток, який демонструє її функціонал. Експортувати клас Angle разом із перевантаженими операціями.

## Проєкт Visual Studio

Рішення містить консольний клієнт `lb6_OOP` і динамічну бібліотеку `Angle`.
`ANGLE_EXPORTS` задано лише під час збирання DLL. Клієнт підключає імпортну бібліотеку.
DLL і EXE збираються в один каталог; для запуску `Angle.dll` потрібна поряд із EXE.
ЛР6 використовує клас із перевантаженими операціями з лабораторної роботи 4.

Файли рішення та вихідного коду:

- `lb6_OOP.sln`
- `lb6_OOP.slnx`
- `lb6_OOP/lb6_OOP.vcxproj`
- `lb6_OOP/lb6_OOP.vcxproj.filters`
- `lb6_OOP/main.cpp`
- `Angle/Angle.vcxproj`
- `Angle/Angle.vcxproj.filters`
- `Angle/Angle.h`
- `Angle/Angle.cpp`

## Збирання та запуск

1. Завантажити гілку `lab6` репозиторію `laby_OOP`.
2. Відкрити `lb6_OOP.slnx`; за потреби використати `lb6_OOP.sln`.
3. Вибрати `Debug` або `Release`, платформа `x64`, та зібрати рішення.
4. Запустити консольний проєкт `lb6_OOP` без аргументів для демонстрації.

У проєкті задано C++17, вимкнено предкомпільовані заголовки. Потрібні
засоби розробки класичних програм C++ та встановлений Windows SDK.
Обидва файли рішення відкривають той самий набір проєктів.

Аргумент `--read` після демонстрації додатково вмикає введення кута.
Наприклад, `0 -30` задає від’ємний кут у пів градуса; хвилини — від -59 до 59.

## Перевірка

Рішення успішно зібрано в Debug x64 і Release x64. Демонстраційний вивід
збігається зі звітом. У GitHub зберігаються вихідні файли та файли Visual Studio;
тимчасові файли й результати збирання виключено через `.gitignore`.
